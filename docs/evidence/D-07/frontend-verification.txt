Behaviour
---------
- Post receipt shown only when the server returns actions.post; disabled while the editor has unsaved changes.
- Dialog: PO line / ordered / posted earlier / this receipt / left after posting, accepted chassis; "Received at"
  from /me locationScope (required; preselected only when exactly one location — no invented default, OQ-24);
  impact: accepted units → awaiting PDI, not saleable; rejected units → no vehicle; missing chassis warning.
- One action + Idempotency-Key per confirmation; button disabled while pending ("Posting…").
- Errors: POSTING_BLOCKED (per-line blockers), DUPLICATE_IDENTIFIER, VERSION_CONFLICT / INVALID_STATE (re-read +
  "changed since you opened this dialog"), IDEMPOTENCY_KEY_REUSED, 401/403/404/422, 5xx/network/invalid response
  = outcome unknown → re-read; still DRAFT → "Send the same request again" (same key); now POSTED →
  "Show the posting result" (same key, server replays; no second posting).
- Success shown only from the server answer; units listed from the result / GET /vehicle-units?goodsReceiptId.
