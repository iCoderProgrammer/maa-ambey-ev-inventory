API contract (exact: docs/API_CONVENTIONS.md "Vehicle units (D-04)", docs/openapi/*)
------------------------------------------------------------------------------------
GET /vehicle-units                        vehicle_units.view
  q (unit number, chassis/frame, motor, battery, charger; normalised substring; % and _ literal)
  status, saleable, brandId, modelId*, variantId, supplierId, purchaseOrderId, goodsReceiptId, locationId,
  receivedFrom*, receivedTo* (YYYY-MM-DD inclusive), minAgeDays*, maxAgeDays* (0-36500 inclusive),
  sort* (-createdAt default | createdAt | -receivedDate | receivedDate | unitNumber | -unitNumber; id tie-break),
  page >= 1, limit 1-100 (25). Items gain ageDays*.      (* = new in D-08)
GET /vehicle-units/{id}                   vehicle_units.view
  + documents* [{attachmentId, sourceType GOODS_RECEIPT|PDI_INSPECTION, sourceId, sourceReference, documentType
    DELIVERY_CHALLAN|SUPPLIER_INVOICE|PHOTO|OTHER|PDI_EVIDENCE, fileName, contentType, sizeBytes, createdAt}],
  + documentsHidden* (true exactly when the caller lacks attachments.view)
GET /vehicle-units/{id}/stock-movements*  vehicle_units.view
  order asc (default) | desc, page, limit 1-100 (50) -> {items: VehicleUnitMovement[], page, limit, total}
  VehicleUnitMovement: id, movementType, fromStatus, toStatus, from/to LocationId/Code/Name, sourceType
  GOODS_RECEIPT|PDI_INSPECTION|STAFF_ACTION, sourceId, sourceReference, actorId, actorName, note, createdAt
Errors: 401; 403 FORBIDDEN (no vehicle_units.view; neighbouring permissions grant nothing); 404 NOT_FOUND (unknown,
invalid or out-of-scope unit); 422 VALIDATION_FAILED with field details. No write routes (405).
