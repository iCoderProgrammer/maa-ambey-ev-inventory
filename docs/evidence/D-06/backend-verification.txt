Schema (000019)
---------------
- permissions: vehicle_units.pdi.record, vehicle_units.pdi.checklist.manage (no grants)
- pdi_checklist_items: code/label/description/brand_id(NULL = all)/sort_order/status ACTIVE|RETIRED/version;
  unique active (code, brand_id) NULLS NOT DISTINCT; guard: no delete, only ACTIVE -> RETIRED once. No item seeded.
- pdi_inspections (append-only): PDI-000001 numbers, unit, disposition, result, from/to (CHECK = approved edges only),
  location, notes (required unless PASS), movement_id (unique FK), inspected_by/at, idempotency (unique per inspector)
- pdi_inspection_items (append-only): PASS/FAIL per checklist item, note required for FAIL
- pdi_inspection_attachments (append-only): attachment linked once (unique attachment_id)
- deferred guards: pdi_inspections_check (movement matches; outcome brand; evidence owner + location; PASS has
  all-PASS outcomes; HOLD/REJECT have evidence), stock_movements_pdi_check (PDI_INSPECTION movement has its inspection)
- stock_movements: source PDI_INSPECTION for PDI_PASS/QUALITY_HOLD/REJECT (source_id + reference required);
  unique stock_movements_pdi_once (source_id). E-01 CHECKs on transitions unchanged.
- down: refuses while any checklist item, inspection or PDI movement exists; restores the 000018 source CHECKs.
