"context canceled" (session lookup 15, access lookup 7, catalogue 6, supplier detail 3, role matrix 2). Latency
0.19–38.98 ms, far below REQUEST_TIMEOUT=15s (a timeout gives "deadline exceeded", not "canceled"). No mutation, no
other ERROR line. Run 1: 26 such requests, same pattern (max 17 ms), no other cause.
Conclusion: request contexts cancelled because the client went away (TanStack Query aborting on navigation/unmount,
pages closed at test end, forwarded by the Vite proxy). The status is never delivered to a client. Same pattern
recorded for C-06 (7) and D-01 (16) and spread across pre-D-01 modules (auth, access, catalogue) — not a D-01
regression; no fix made. Observation only: the API logs client aborts as ERROR/5xx, which is log noise
(cross-cutting; candidate for a separate task if wanted).
